# M10 — manual checks (altri host: stampante, Smart TV, server DNS e DHCP)

Build and open: `scripts/bundle.sh && open build/PacTrack.app`.

**Palette e menu**
- [ ] La palette ha le sezioni RETE (Router, Switch, Hub, Cloud/ISP), HOST (PC, Laptop, Stampante, Smart TV), SERVER (Server, Server DNS, Server DHCP) e CAVI. Ogni voce ha la sua icona e sta su una riga, anche con la finestra alla dimensione minima.
- [ ] *Cerca*: `stamp` mostra solo Stampante, `tv` solo Smart TV, `server` tutta la sezione SERVER, `dhcp` solo Server DHCP, `zzz` mostra "Nessun dispositivo".
- [ ] Clic destro sul canvas ▸ *Aggiungi dispositivo*: le stesse voci nello stesso ordine, preset compresi; ognuna aggiunge il dispositivo sotto il puntatore.

**Stampante e Smart TV**
- [ ] Trascina una Stampante: si chiama `PRN1`, icona stampante, nessun indirizzo. Schede Interfacce, Routing, Servizi, Tabelle, App; *Servizi* mostra solo *Sink TCP/UDP (porta 9)*, acceso, con "Riceve e scarta il traffico del generatore.". Spegnendolo il testo dice che TCP risponde con RST.
- [ ] Trascina una Smart TV: si chiama `TV1`, icona televisore, eth0 già in *DHCP*. Schede come un PC (senza Servizi). Il menu del dispositivo ha *Rinnova DHCP*.
- [ ] Cmd+Z dopo ciascuno toglie il dispositivo con il suo default in un passo.

**Server DNS e Server DHCP**
- [ ] Server DHCP: `SRV1`, eth0 `192.168.1.2/24`, *Servizi* con *Server DHCP* acceso, pool `192.168.1.100`–`192.168.1.199`, gateway e DNS vuoti.
- [ ] Server DNS: eth0 `192.168.1.3/24`, *Server DNS* acceso senza record.
- [ ] Un Cmd+Z toglie il server preconfigurato in un passo. Salvato e riaperto è un normale server con il suo servizio.

**Il laboratorio della spec**
- [ ] SW1 con Server DHCP (SRV1), Smart TV (TV1), Stampante (PRN1) e PC (PC1), cavi diretti. Solo PRN1 `192.168.1.50/24` e PC1 in DHCP.
- [ ] A 60 s TV1 e PC1 hanno `192.168.1.100/24` e `192.168.1.101/24` (BOUND, server 192.168.1.2); prima le porte di SW1 sono in listening/learning e i DISCOVER si ripetono a 4, 12 e 28 s.
- [ ] App di PC1, generatore TCP verso `192.168.1.50`, 100000 byte → `iperf Done.`; negli eventi i segmenti arrivano a PRN1 eth0. Lo stesso dalla Smart TV.
- [ ] Ping da PRN1 a PC1 risponde. Sulla Smart TV il sink non c'è.

**Copie e file**
- [ ] Duplica PRN1: `PRN2` con il sink acceso. Spegni il sink di PRN2 e duplicalo: la copia ha il sink spento. Duplica SRV1 (Server DHCP): la copia è un server senza indirizzo e senza pool; un server con il sink acceso lo copia acceso.
- [ ] Salva, chiudi e riapri: stampante con il suo sink (acceso o spento), Smart TV in DHCP, i server con i loro servizi. Un progetto M9 si apre come prima.
- [ ] *File ▸ Esporta immagine…*: le icone di stampante e televisore compaiono nel PNG.
