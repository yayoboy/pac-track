# M3 — manual checks

Build and open: `scripts/bundle.sh && open build/PacTrack.app`. Start from a switch with a Server SRV1 (10.0.0.2/24) and two PCs.

**DHCP server**
- [ ] SRV1 ▸ Servizi ▸ *Server DHCP* on: pool 10.0.0.100–10.0.0.199, lease 86400 s appear; with *Server DNS* already on, the DNS field shows 10.0.0.2.
- [ ] Type `10.0.1.5` as *Inizio pool*: red error under the field, the pool stays as it was. Type `abc` as lease: "Invalid number".
- [ ] A router with Gi0/0 10.0.0.1/24: *Server DHCP* on suggests itself as gateway. Without any address: "Assign an IPv4 address to an interface first".
- [ ] Cmd+Z after turning the server on turns it off again (one step).

**DHCP clients**
- [ ] PC1 ▸ Interfacce ▸ *DHCP*: the IP field becomes read-only, "in attesa…" then 10.0.0.100/24 with "BOUND · server 10.0.0.2 · lease … · rinnovo tra … s"; the canvas shows the address.
- [ ] Event list: DHCP Discover / Offer / Request / ACK rows in blue; click Offer: Ethernet / IPv4 / UDP / DHCP with xid, flags, yiaddr, chaddr, options 53/51/54/1/3/6, padding; frame 342 B.
- [ ] Set lease 60 s, PC1 *Rinnova DHCP* (context menu): a unicast Request and ACK appear; after ~30 s a renewal happens by itself (T1).
- [ ] Switch SRV1 off: at T2 a broadcast Request, at expiry PC1 loses its address (Tabelle: routing loses the DHCP route).
- [ ] Back to *Statico*: a DHCP Release appears and SRV1's lease table empties.
- [ ] Router with a pool on Gi0/0 and a PC on Gi0/1: the PC gets no address (no DHCP relay) and nothing leaves Gi0/1.
- [ ] Save, close, reopen: PCs are still in DHCP mode and get an address again; SRV1's pool and records are kept.

**DNS**
- [ ] SRV1 ▸ Servizi ▸ *Server DNS* on; add `srv1.lab` → 10.0.0.2 (empty TTL = 3600); `bad name` shows an error under the form; ✕ removes a record.
- [ ] PC1 ▸ App ▸ `srv1.lab` ▸ *nslookup*: Server/Address/Name/Address lines; `nope.lab` prints `** server can't find nope.lab: NXDOMAIN`.
- [ ] PC2 ▸ App ▸ Ping `srv1.lab`: "PING srv1.lab (10.0.0.2)…"; Tabelle ▸ *Cache DNS* lists srv1.lab with a decreasing TTL; a second ping sends no DNS query.
- [ ] Event list: DNS rows in purple; a response shows flags 0x8500 and the answer with its TTL.
- [ ] Filters: toggling DHCP or DNS hides those rows.
