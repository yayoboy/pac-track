# M9a — IPv6 core: addresses, NDP, DAD, SLAAC, ICMPv6 (Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hosts and routers run IPv6 next to IPv4 on the same interfaces (spec M9 §1–§9):
- link-local EUI-64 addresses, manual global addresses, Duplicate Address Detection;
- NDP address resolution with a neighbour cache that walks INCMP/REACH/STALE/DELAY/PROBE;
- routers with `ipv6 unicast-routing` send Router Advertisements; hosts solicit them (RFC 7559 back-off) and autoconfigure (SLAAC) with a default route `ND ::/0 [2/0]`;
- ICMPv6 echo and errors (no route, address and port unreachable, packet too big, hop limit), ping and traceroute to IPv6 literals;
- static IPv6 routes, forwarding with the hop limit;
- the UI shows the addresses, the IPv6 routing table and the neighbours, a router switch for `ipv6 unicast-routing`, the NDP filter and the IPv6/ICMPv6 PDU layers; `.ptk` saves it all.

**Architecture:**
- `PacEngine` gains:
  - `Ipv6Pdu.swift`: 128-bit addresses (`UInt128`, RFC 4291/5952 text), `Ipv6Packet`, `Ipv6Payload` (ICMPv6 reusing `IcmpMessage`, `NdpMessage`, UDP), serialisation and pseudo-header checksums; `L3.ipv6`;
  - `L3/Ipv6.swift`: the per-node stack `Ipv6` (`IpNode.v6`): per-interface `Ipv6Iface` on `Interface.v6`, DAD, RS/RA, SLAAC, routes, input/output, ICMPv6 errors;
  - `L3/Ndp.swift`: `NeighborCache` (RFC 4861 §7.2–7.3);
  - Ping and Traceroute take IPv6 literals.
- `IpNode` hands IPv6 frames and line/power changes to `v6`; IPv4 code paths do not change.
- `Command.setIpv6`/`.setIpv6Routing`, `IfaceView.ipv6Config`/`ipv6`, `NodeView.ipv6Routing`/`neighbors6`, `RouteRow.ra`, `TopologyIface.ipv6`, `TopologyNode.ipv6Routing` carry it to `PacKit` (`makeTopology`, copies, `routeColumns` "ND") and `PacTrack`.

**Tech Stack:** Swift 6.3, SwiftUI + AppKit (macOS 15), Observation, Swift Testing, SwiftPM, Command Line Tools only — no Xcode.

**Spec:** `docs/superpowers/specs/2026-10-11-m9-ipv6-design.md` §1–§9 and the M9a parts of §11 (M9b, §10, is not in this plan). It extends `docs/superpowers/specs/2026-10-07-pac-track-rewrite-design.md` (rev. 2), M7 and M8.

2. **Lines and power flapping.** DAD runs again when the line comes back or the device is switched on; nothing happens while the line is down; RS/RA start over after DAD. Pinned by `dadWaitsForTheLineAndRunsAgainWhenItComesBack`, `aPowerCycleRunsDadAgain` (Task 2) and `theDefaultRouterLastsTheRouterLifetimeAndAFinalAdvertisementRemovesIt` (Task 4).
3. **A switch without PortFast between host and router.** The first RS die in spanning tree's 30 s; the RFC 7559 back-off still gets the host its address at 61 s instead of the 200 s periodic RA. Pinned by `ipv6RunsOnASubinterfaceBehindASwitchWithoutPortFast` (Task 5).
4. **Long-running windows.** The RS interval stops doubling at 3600 s (no overflow over simulated hours); payload lengths never trap. Pinned by `solicitationsBackOffUntilARouterAdvertises` (runs to 8000 s; Task 4).
5. **Routers with NAT and a firewall.** IPv6 passes them untouched while IPv4 is translated and filtered as before. Pinned by `natAndTheFirewallLeaveIpv6Alone` (Task 5).

## Rulings (where the spec is silent)

Each line gives the ruling, why, and the cost if wrong.

- **A separate stack object.** IPv6 lives in `Ipv6` (`IpNode.v6`, lazy) with `NeighborCache`; the IPv4 methods of `IpNode` are not touched. Why: the IPv4 path is the most tested code in the project. Cost if wrong: some duplicated shape (send/output/error).
- **ICMPv6 reuses `IcmpMessage`.** Echo and errors have ICMPv4's header layout; Packet Too Big's 32-bit MTU sits in `id` (high) and `seq` (low), exactly the same 4 bytes on the wire. Why: one struct, one `serialize`. Cost if wrong: none on the wire.
- **`Ipv6Payload` is not `L4`.** IPv6 carries its own enum (ICMP, NDP, UDP), so IPv4's exhaustive switches stay as they are. Cost if wrong: none.
- **The NIC filter for `33:33`** accepts a MAC when the physical interface or one of its subinterfaces has joined the group; the IP layer checks the group again on the logical interface. Why: a NIC has one multicast filter for all its VLAN devices. Cost if wrong: none.
- **IPv6 static routes share IPv4's plumbing:** `Command.addRoute`/`.removeRoute`, `TopologyRoute`, `NodeView.routes` (IPv4 rows first, then IPv6). A destination with `:` is IPv6; the Tabelle tab splits the rows by that. Why: the Routing tab, saving and copies need no change. Cost if wrong: none.
- **New drop reasons** `nd-timeout` and `nd-pending-full`; `SimEvent.packet6` carries an IPv6 packet dropped above the link. Why: `arp-*` would mislead. Cost if wrong: none.
- **DAD, RS and RA leave from the scheduler** (a deadline at `now`), never inline from a command, except a change on a running device: SLAAC turned on sends its RS and `ipv6 unicast-routing` turned off its last RA at once, as `Rip.reconfigure` does. Why: a device switched off in the same instant (a file opening with it off, undo) sends nothing, as in `Rip.startDue`; loading never turns SLAAC on over an existing setting nor routing off. Cost if wrong: none.
- **Unicast NS source:** the waiting packet's source if it is a usable address of the interface, otherwise the interface's usable address of the target's scope, otherwise any usable one (RFC 4861 §7.2.2). Cost if wrong: none.
- **Replies to a link-local source** (echo reply, port unreachable) leave through the interface the request came in on. Why: a link-local destination has no route. Cost if wrong: none.
- **The UI sends `.setIpv6` directly**, building the config from the snapshot, like the IPv4 field sends `.setIp`: no `Editor` helper. Errors use the key `ip6:<node>:<iface>` (fields) and `ip6:<node>` (routing switch). Cost if wrong: none.
- **Routers and the Cloud never process RAs.** Only `Host` learns default routers and autoconfigures. Cost if wrong: none (spec §5).

```swift
/// RFC 4291 §2.2 text: groups of 1–4 hex digits in any case, at most one "::". No dotted IPv4 tail and no zone (spec M9 §2).
func parseIp6(_ s: String) throws -> UInt128 {
    let bad = EngineError("Invalid IPv6 address: \"\(s)\"")
    let halves = s.components(separatedBy: "::")
    guard halves.count <= 2 else { throw bad }
    func groups(_ part: String) throws -> [UInt128] {
        guard !part.isEmpty else { return [] }
        return try part.split(separator: ":", omittingEmptySubsequences: false).map { g in
            guard (1...4).contains(g.count), g.allSatisfy({ $0.isASCII && $0.isHexDigit }), let v = UInt16(g, radix: 16) else { throw bad }
            return UInt128(v)
        }
    }
    let head = try groups(halves[0])
    let tail = try halves.count == 2 ? groups(halves[1]) : []
    let count = head.count + tail.count
    guard halves.count == 2 ? count <= 7 : count == 8 else { throw bad }
    return (head + Array(repeating: 0, count: 8 - count) + tail).reduce(0) { $0 << 16 | $1 }
}

/// RFC 5952: lowercase, no leading zeros, the longest run of two or more zero groups (the first on a tie) written "::".
func formatIp6(_ a: UInt128) -> String {
    let g = (0..<8).map { Int(truncatingIfNeeded: a >> (112 - 16 * $0)) & 0xFFFF }
    var run = (start: 0, length: 0)
    var i = 0
    while i < 8 {
        var j = i
        while j < 8 && g[j] == 0 { j += 1 }
        if j - i > run.length { run = (i, j - i) }
        i = j + 1
    }
    let text = { (part: ArraySlice<Int>) in part.map { String($0, radix: 16) }.joined(separator: ":") }
    guard run.length >= 2 else { return text(g[...]) }
    return text(g[..<run.start]) + "::" + text(g[(run.start + run.length)...])
}

/// "2001:db8::1/64"; the prefix is 0–128.
func parseCidr6(_ s: String) throws -> Cidr6 {
    let parts = s.split(separator: "/", omittingEmptySubsequences: false)
    guard parts.count == 2, (1...3).contains(parts[1].count), parts[1].allSatisfy({ $0.isASCII && $0.isNumber }),
          let prefix = Int(parts[1]), prefix <= 128 else { throw EngineError("Invalid IPv6 prefix: \"\(s)\"") }
    return Cidr6(addr: try parseIp6(String(parts[0])), prefix: prefix)
}

func prefixMask6(_ prefix: Int) -> UInt128 {
    prefix == 0 ? 0 : UInt128.max << (128 - prefix)
}

func networkOf6(_ a: UInt128, _ prefix: Int) -> UInt128 {
    a & prefixMask6(prefix)
}

func inSubnet6(_ a: UInt128, _ network: UInt128, _ prefix: Int) -> Bool {
    networkOf6(a, prefix) == networkOf6(network, prefix)
}

/// fe80::/10.
func isLinkLocal6(_ a: UInt128) -> Bool {
    a >> 118 == 0x3FA
}

/// ff00::/8.
func isMulticast6(_ a: UInt128) -> Bool {
    a >> 120 == 0xFF
}

func macBytes(_ mac: Mac) -> [UInt8] {
    mac.split(separator: ":").map { UInt8($0, radix: 16) ?? 0 }
}

/// Modified EUI-64 interface identifier (RFC 4291 app. A): the MAC with the U/L bit flipped and ff:fe in the middle.
func eui64(_ mac: Mac) -> UInt128 {
    var b = macBytes(mac)
    b[0] ^= 0x02
    return (Array(b[0..<3]) + [0xFF, 0xFE] + Array(b[3..<6])).reduce(0) { $0 << 8 | UInt128($1) }
}

/// fe80::/64 + EUI-64 (spec M9 §2).
func linkLocal(_ mac: Mac) -> UInt128 {
    LINK_LOCAL_PREFIX | eui64(mac)
}

/// ff02::1:ff00:0/104 + the address's low 24 bits (RFC 4291 §2.7.1).
func solicitedNode(_ a: UInt128) -> UInt128 {
    UInt128(0xFF02) << 112 | UInt128(0x1_FF00_0000) | a & 0xFF_FFFF
}

/// 33:33 + the group's low 32 bits (RFC 2464 §7).
func multicastMac6(_ group: UInt128) -> Mac {
    "33:33:" + (0..<4).map { hex2(Int(truncatingIfNeeded: group >> (24 - 8 * $0)) & 0xFF) }.joined(separator: ":")
}

/// The 16 bytes of an address, network order.
func bytes16(_ a: UInt128) -> [UInt8] {
    (0..<16).map { UInt8(truncatingIfNeeded: a >> (120 - 8 * $0)) }
}

/// A Prefix Information option (RFC 4861 §4.6.2) as IOS sends it: on-link and autonomous, with IOS's lifetimes.
struct PrefixInfo: Equatable, Sendable {
    var prefix: UInt128
    var length: Int
    var valid = ND_VALID_LIFETIME
    var preferred = ND_PREFERRED_LIFETIME
}

/// A Router Advertisement with IOS defaults (spec M9 §5): flags M and O, reachable time and retrans timer are 0.
struct RouterAdvert: Equatable, Sendable {
    var hopLimit: UInt8 = 64
    var lifetime = RA_LIFETIME_S
    var slla: Mac
    var mtu = RA_MTU
    var prefixes: [PrefixInfo]
}

/// NDP bodies (RFC 4861 §4) with the link-layer address options Pac-Track uses; an NA always carries the target's.
enum NdpBody: Equatable, Sendable {
    case rs(slla: Mac?)
    case ra(RouterAdvert)
    case ns(target: UInt128, slla: Mac?)
    case na(target: UInt128, router: Bool, solicited: Bool, override: Bool, tlla: Mac)
}

/// An NDP message: an ICMPv6 message with its own body.
struct NdpMessage: Equatable, Sendable {
    var body: NdpBody
    var checksum: UInt16 = 0

    var type: UInt8 {
        switch body {
        case .rs: ND_RS
        case .ra: ND_RA
        case .ns: ND_NS
        case .na: ND_NA
        }
    }

    /// Header and fields, plus 8 B per link-layer address option, 8 B of MTU and 32 B per prefix.
    var size: Int {
        switch body {
        case .rs(let slla): 8 + (slla == nil ? 0 : 8)
        case .ra(let ra): 32 + 32 * ra.prefixes.count
        case .ns(_, let slla): 24 + (slla == nil ? 0 : 8)
        case .na: 32
        }
    }
}

/// What an IPv6 packet carries: ICMPv6 echo and errors (ICMPv4's header layout, so `IcmpMessage`), NDP, UDP.
enum Ipv6Payload: Equatable, Sendable {
    case icmp(IcmpMessage)
    case ndp(NdpMessage)
    case udp(UdpDatagram)

    var size: Int {
        switch self {
        case .icmp(let m): m.size
        case .ndp(let n): n.size
        case .udp(let u): u.size
        }
    }

    var nextHeader: UInt8 {
        switch self {
        case .icmp, .ndp: IPPROTO_ICMPV6
        case .udp: IPPROTO_UDP
        }
    }
}

/// The 40-byte IPv6 header (RFC 8200) with traffic class and flow label 0 and no extension headers (spec M9 §3).
struct Ipv6Packet: Equatable, Sendable {
    var hopLimit: UInt8
    var src: UInt128
    var dst: UInt128
    var payload: Ipv6Payload

    var size: Int { 40 + payload.size }
}

func serializeHeader(_ p: Ipv6Packet) -> [UInt8] {
    var b: [UInt8] = [0x60, 0, 0, 0]
    b += u16(UInt16(truncatingIfNeeded: p.payload.size))
    b += [p.payload.nextHeader, p.hopLimit]
    return b + bytes16(p.src) + bytes16(p.dst)
}

private func llaOption(_ type: UInt8, _ mac: Mac) -> [UInt8] {
    [type, 1] + macBytes(mac)
}

func serialize(_ m: NdpMessage) -> [UInt8] {
    var b: [UInt8] = [m.type, 0]
    b += u16(m.checksum)
    switch m.body {
    case .rs(let slla):
        b += u32(0)
        if let slla { b += llaOption(1, slla) }
    case .ra(let ra):
        b += [ra.hopLimit, 0]
        b += u16(ra.lifetime)
        b += u32(0) + u32(0) // reachable time, retrans timer
        b += llaOption(1, ra.slla)
        b += [5, 1, 0, 0] + u32(ra.mtu)
        for p in ra.prefixes {
            b += [3, 4, UInt8(truncatingIfNeeded: p.length), 0xC0] // L and A
            b += u32(p.valid) + u32(p.preferred) + u32(0) + bytes16(p.prefix)
        }
    case .ns(let target, let slla):
        b += u32(0) + bytes16(target)
        if let slla { b += llaOption(1, slla) }
    case .na(let target, let router, let solicited, let override, let tlla):
        let flags: UInt8 = (router ? 0x80 : 0) | (solicited ? 0x40 : 0) | (override ? 0x20 : 0)
        b += [flags, 0, 0, 0] + bytes16(target) + llaOption(2, tlla)
    }
    return b
}

func serializePayload(_ p: Ipv6Packet) -> [UInt8] {
    switch p.payload {
    case .icmp(let m): serialize(m)
    case .ndp(let n): serialize(n)
    case .udp(let u): serialize(u)
    }
}

/// What ICMPv6 and UDP checksums cover besides the message (RFC 8200 §8.1).
func pseudoHeader6(_ src: UInt128, _ dst: UInt128, _ length: Int, _ nextHeader: UInt8) -> [UInt8] {
    bytes16(src) + bytes16(dst) + u32(UInt32(truncatingIfNeeded: length)) + [0, 0, 0, nextHeader]
}

/// A packet with its payload's checksum filled in: mandatory for ICMPv6 and for UDP over IPv6, where a sum of 0 is sent as ffff.
func makeIpv6(src: UInt128, dst: UInt128, hopLimit: UInt8, payload: Ipv6Payload) -> Ipv6Packet {
    let pseudo = pseudoHeader6(src, dst, payload.size, payload.nextHeader)
    let sealed: Ipv6Payload
    switch payload {
    case .icmp(var m):
        m.checksum = 0
        m.checksum = internetChecksum(pseudo + serialize(m))
        sealed = .icmp(m)
    case .ndp(var n):
        n.checksum = 0
        n.checksum = internetChecksum(pseudo + serialize(n))
        sealed = .ndp(n)
    case .udp(var u):
        u.checksum = 0
        let sum = internetChecksum(pseudo + serialize(u))
        u.checksum = sum == 0 ? 0xFFFF : sum
        sealed = .udp(u)
    }
    return Ipv6Packet(hopLimit: hopLimit, src: src, dst: dst, payload: sealed)
}
```

```swift
/// RFC 4861 RetransTimer (IOS `ipv6 nd ns-interval` 1000 ms): DAD waits this long for an answer (spec M9 §5).
let ND_RETRANS_NS = 1 * S
/// Hop limit of the packets a host or router originates (Linux and IOS default, spec M9 §3).
let HOP_LIMIT6: UInt8 = 64

enum AddrOrigin: Sendable {
    case linkLocal, manual, slaac
}

enum DadState: Sendable {
    case tentative, preferred, duplicate
}

/// One IPv6 address of an interface with its DAD state (RFC 4862 §5.4).
struct Addr6 {
    let addr: UInt128
    let prefix: Int
    let origin: AddrOrigin
    var state = DadState.tentative
    /// While tentative: the next DAD step, sending the NS and then (once `probed`) taking the address; nil until the line is up.
    var dadDue: Int? = nil
    var probed = false
}

/// IPv6 on one interface (spec M9 §2): its settings, addresses and line state.
struct Ipv6Iface {
    var config: Ipv6Config
    /// The link-local address first, then the manual one and the SLAAC ones.
    var addrs: [Addr6]
    /// The line state last seen: DAD runs again when it comes back up (spec M9 §5).
    var lineWasUp: Bool
}

/// The IPv6 stack of a host or router (spec M9), idle until an interface turns IPv6 on. Timers are deadlines checked in `expire`,
/// as in `Rip`: an expiry does nothing if its deadline was moved or cleared since.
final class Ipv6 {
    unowned let node: IpNode
    var hopLimit = HOP_LIMIT6

    init(node: IpNode) {
        self.node = node
    }

    private var now: Int { node.sim.now }

    /// IPv6 on with these settings, or off with nil (spec M9 §2). A new address starts tentative; DAD runs when the line is up.
    func configure(_ name: String, _ config: Ipv6Config?) throws {
        let iface = try node.iface(name)
        guard let config else {
            iface.v6 = nil
            return
        }
        let manual = try config.address.map { try manualAddress($0, on: iface) }
        var v6 = iface.v6 ?? Ipv6Iface(config: config, addrs: [Addr6(addr: linkLocal(iface.mac), prefix: 64, origin: .linkLocal)], lineWasUp: iface.lineUp)
        v6.config = config
        v6.addrs.removeAll { $0.origin == .manual && ($0.addr != manual?.addr || $0.prefix != manual?.prefix) }
        if let manual, !v6.addrs.contains(where: { $0.origin == .manual }) {
            v6.addrs.append(Addr6(addr: manual.addr, prefix: manual.prefix, origin: .manual))
        }
        iface.v6 = v6
        dad(iface)
    }

    /// IOS `ipv6 address X/len` rules (spec M9 §2): a unicast global or unique-local address, not the Subnet-Router anycast one,
    /// in a prefix no other interface of the device overlaps.
    private func manualAddress(_ text: String, on iface: Interface) throws -> Cidr6 {
        let t = text.trimmingCharacters(in: .whitespaces)
        let c = try parseCidr6(t)
        guard c.prefix >= 1 else { throw EngineError("Invalid IPv6 prefix: \"\(t)\"") }
        guard c.addr > 1, !isMulticast6(c.addr), !isLinkLocal6(c.addr) else {
            throw EngineError("\(formatIp6(c.addr)) cannot be assigned: it is unspecified, loopback, multicast or link-local")
        }
        if c.prefix <= 126 && c.addr == networkOf6(c.addr, c.prefix) { throw EngineError("\(t) is the Subnet-Router anycast address") }
        for other in node.interfaces where other !== iface {
            if other.v6?.addrs.contains(where: { $0.origin != .linkLocal && inSubnet6(c.addr, $0.addr, min(c.prefix, $0.prefix)) }) == true {
                throw EngineError("\(t) overlaps with \(other.name)")
            }
        }
        return c
    }

    /// An address of this device in use (not tentative, not duplicate), on any interface: the weak host model of Linux and IOS.
    func owns(_ a: UInt128) -> Bool {
        node.interfaces.contains { $0.v6?.addrs.contains { $0.addr == a && $0.state == .preferred } == true }
    }

    /// The NIC filter for `33:33` MACs: a group that `phys` or one of its subinterfaces has joined (spec M9 §2).
    func listens(_ mac: Mac, on phys: Interface) -> Bool {
        node.interfaces.contains { i in (i.dot1q?.parent ?? i) === phys && groups(i).contains { multicastMac6($0) == mac } }
    }

    /// The groups an interface has joined: all-nodes, and each address's solicited-node group.
    private func groups(_ i: Interface) -> [UInt128] {
        guard let v6 = i.v6 else { return [] }
        return [ALL_NODES] + v6.addrs.map { solicitedNode($0.addr) }
    }

    /// A packet that reached an interface: for a group it joined or an address in use, else ignored.
    func input(_ p: Ipv6Packet, on iface: Interface) {
        guard iface.v6 != nil else { return } // IPv6 off: like an unknown EtherType
        if isMulticast6(p.dst) {
            if groups(iface).contains(p.dst) { deliver(p, on: iface) }
            return
        }
        if owns(p.dst) { deliver(p, on: iface) }
    }

    private func deliver(_ p: Ipv6Packet, on iface: Interface) {
        switch p.payload {
        case .ndp(let n): receive(n, p, on: iface)
        case .icmp, .udp: break
        }
    }

    /// NDP, only from the link itself (hop limit 255, RFC 4861 §6.1, §7.1): DAD (RFC 4862 §5.4.3–5.4.4).
    private func receive(_ n: NdpMessage, _ p: Ipv6Packet, on iface: Interface) {
        guard p.hopLimit == 255 else { return }
        switch n.body {
        case .ns(let target, _):
            guard let k = iface.v6!.addrs.firstIndex(where: { $0.addr == target }) else { return }
            switch iface.v6!.addrs[k].state {
            case .tentative:
                if p.src == 0 { duplicate(iface, k) } // another node's DAD for the same address
            case .duplicate:
                break
            case .preferred:
                // Another node's DAD for an address in use here: the answer goes to every node (RFC 4861 §7.2.4).
                if p.src == 0 {
                    sendNdp(.na(target: target, router: false, solicited: false, override: true, tlla: iface.mac), src: target, dst: ALL_NODES, on: iface)
                }
            }
        case .na(let target, _, _, _, _):
            if let k = iface.v6!.addrs.firstIndex(where: { $0.addr == target }), iface.v6!.addrs[k].state == .tentative { duplicate(iface, k) }
        case .rs, .ra:
            break
        }
    }

    /// DAD failed: the address is never used (spec M9 §5).
    private func duplicate(_ iface: Interface, _ k: Int) {
        iface.v6!.addrs[k].state = .duplicate
        iface.v6!.addrs[k].dadDue = nil
        node.sim.emit(.state, node: node.id, iface: iface.name, note: "DAD: \(formatIp6(iface.v6!.addrs[k].addr)) duplicato", proto: .ndp)
    }

    private func sendNdp(_ body: NdpBody, src: UInt128, dst: UInt128, on iface: Interface) {
        let p = makeIpv6(src: src, dst: dst, hopLimit: 255, payload: .ndp(NdpMessage(body: body)))
        node.sendFrame(iface, to: multicastMac6(dst), etherType: ETHERTYPE_IPV6, .ipv6(p))
    }

    /// Starts DAD for every tentative address of `iface` not yet under way, if its line is up. The NS leaves from the scheduler,
    /// so a device switched off in the same instant sends nothing.
    private func dad(_ iface: Interface) {
        guard iface.lineUp, let addrs = iface.v6?.addrs else { return }
        for k in addrs.indices where addrs[k].state == .tentative && addrs[k].dadDue == nil {
            iface.v6!.addrs[k].dadDue = arm(now)
        }
    }

    /// Every address back to tentative, no timer running.
    private func rewind(_ iface: Interface) {
        guard iface.v6 != nil else { return }
        for k in iface.v6!.addrs.indices {
            iface.v6!.addrs[k].state = .tentative
            iface.v6!.addrs[k].dadDue = nil
            iface.v6!.addrs[k].probed = false
        }
    }

    /// The line came back up, or the device was switched on: DAD runs again on every address (spec M9 §5).
    private func restart(_ iface: Interface) {
        rewind(iface)
        iface.v6?.lineWasUp = iface.lineUp
        dad(iface)
    }

    /// Power on.
    func start() {
        for i in node.interfaces where i.v6 != nil { restart(i) }
    }

    /// Power off: what was learned is forgotten, every address waits for DAD again.
    func reset() {
        for i in node.interfaces where i.v6 != nil {
            rewind(i)
            i.v6!.lineWasUp = false
        }
        hopLimit = HOP_LIMIT6
    }

    /// The cable at `phys` changed, or the device at its other end was switched: a line back up restarts its interfaces.
    func linkChanged(_ phys: Interface) {
        for i in node.interfaces where (i.dot1q?.parent ?? i) === phys && i.v6 != nil {
            if i.lineUp && !i.v6!.lineWasUp { restart(i) } else { i.v6!.lineWasUp = i.lineUp }
        }
    }

    private func arm(_ due: Int) -> Int {
        node.sim.sched.at(due) { [weak self] in self?.expire(due) }
        return due
    }

    private func expire(_ due: Int) {
        for i in node.interfaces where i.v6 != nil {
            for k in i.v6!.addrs.indices where i.v6!.addrs[k].dadDue == due {
                let a = i.v6!.addrs[k]
                if !a.probed {
                    // RFC 4862 §5.4.2: one NS from the unspecified address to the solicited-node group, no link-layer address.
                    i.v6!.addrs[k].probed = true
                    i.v6!.addrs[k].dadDue = arm(due + ND_RETRANS_NS)
                    sendNdp(.ns(target: a.addr, slla: nil), src: 0, dst: solicitedNode(a.addr), on: i)
                } else {
                    i.v6!.addrs[k].dadDue = nil
                    i.v6!.addrs[k].state = .preferred
                }
            }
        }
    }
}
```

```swift
/// Neighbour Unreachability Detection (RFC 4861 §7.3, §10; IOS defaults, spec M9 §4): REACH lasts 30 s, the first packet to a
/// STALE entry waits 5 s in DELAY, then PROBE sends up to 3 unicast NS a second apart; address resolution sends up to 3 NS.
let ND_REACHABLE_NS = 30 * S
let ND_DELAY_NS = 5 * S
let ND_MAX_SOLICIT = 3
/// Packets queued while an address resolves, as for ARP.
let ND_PENDING_MAX = ARP_PENDING_MAX

enum NeighborState: String, Sendable {
    case incomplete = "INCMP", reachable = "REACH", stale = "STALE", delay = "DELAY", probe = "PROBE"
}

private final class Neighbor {
    let iface: Interface
    let addr: UInt128
    var mac: Mac?
    var state: NeighborState
    var reachableUntil = 0
    /// INCOMPLETE: what waits for the address.
    var queue: [Ipv6Packet] = []
    var solicits = 0
    /// The next NS (INCOMPLETE, PROBE) or the move to PROBE (DELAY).
    var due: Int?

    init(iface: Interface, addr: UInt128, mac: Mac?, state: NeighborState) {
        self.iface = iface
        self.addr = addr
        self.mac = mac
        self.state = state
    }
}

/// The IPv6 neighbour cache of one node (RFC 4861 §7.2–7.3, spec M9 §4), keyed by interface and address (a link-local address
/// repeats on other links). Entries keep their order of arrival; timers are deadlines checked in `expire`.
// ponytail: linear scans; a lab has a handful of neighbours per node
final class NeighborCache {
    unowned let stack: Ipv6
    private var entries: [Neighbor] = []

    init(stack: Ipv6) {
        self.stack = stack
    }

    private var node: IpNode { stack.node }
    private var now: Int { node.sim.now }

    private func find(_ addr: UInt128, _ iface: Interface) -> Neighbor? {
        entries.first { $0.addr == addr && $0.iface === iface }
    }

    /// REACH turns STALE when its time is over, checked lazily.
    private func state(_ n: Neighbor) -> NeighborState {
        n.state == .reachable && now >= n.reachableUntil ? .stale : n.state
    }

    /// `show ipv6 neighbors`: interfaces in the node's order, then addresses.
    func view() -> [(addr: UInt128, mac: Mac?, state: NeighborState, iface: String)] {
        let order = { (n: Neighbor) in self.node.interfaces.firstIndex { $0 === n.iface } ?? 0 }
        return entries.sorted { (order($0), $0.addr) < (order($1), $1.addr) }.map { ($0.addr, $0.mac, state($0), $0.iface.name) }
    }

    /// Power off: every entry and waiting packet is gone (their timers find nothing).
    func reset() {
        entries = []
    }

    /// IPv6 went off on `iface`, or the interface was deleted.
    func forget(_ iface: Interface) {
        entries.removeAll { $0.iface === iface }
    }

    /// Sends `p` to `addr` on `iface` (RFC 4861 §7.2.2, §7.3.3): an unknown address is resolved first, a STALE entry waits in DELAY.
    func send(_ p: Ipv6Packet, to addr: UInt128, on iface: Interface) {
        guard let n = find(addr, iface) else {
            let fresh = Neighbor(iface: iface, addr: addr, mac: nil, state: .incomplete)
            fresh.queue = [p]
            entries.append(fresh)
            return solicit(fresh)
        }
        switch state(n) {
        case .incomplete:
            if n.queue.count < ND_PENDING_MAX {
                n.queue.append(p)
            } else {
                node.sim.emit(.drop, node: node.id, iface: iface.name, reason: .ndPendingFull, packet6: p)
            }
            return
        case .stale:
            n.state = .delay
            n.due = arm(now + ND_DELAY_NS)
        case .reachable, .delay, .probe:
            break
        }
        frame(p, to: n.mac!, on: iface)
    }

    /// A link-layer address heard in an NS, RS or RA (RFC 4861 §7.2.3, §6.2.6, §6.3.4): a new or changed one is STALE, and what
    /// waited for it leaves.
    func learn(_ addr: UInt128, _ mac: Mac, on iface: Interface) {
        guard let n = find(addr, iface) else {
            entries.append(Neighbor(iface: iface, addr: addr, mac: mac, state: .stale))
            return
        }
        guard n.mac != mac else { return }
        n.mac = mac
        n.state = .stale
        n.due = nil
        flush(n)
    }

    /// A Neighbor Advertisement (RFC 4861 §7.2.5); without an entry it is ignored.
    func advertised(_ addr: UInt128, _ mac: Mac, solicited: Bool, override: Bool, on iface: Interface) {
        guard let n = find(addr, iface) else { return }
        if n.state == .incomplete {
            n.mac = mac
            n.state = solicited ? .reachable : .stale
            n.reachableUntil = now + ND_REACHABLE_NS
            n.due = nil
            return flush(n)
        }
        let changed = n.mac != mac
        if !override && changed {
            if state(n) == .reachable { n.state = .stale }
            return
        }
        n.mac = mac
        if solicited {
            n.state = .reachable
            n.reachableUntil = now + ND_REACHABLE_NS
            n.due = nil
        } else if changed {
            n.state = .stale
            n.due = nil
        }
    }

    private func flush(_ n: Neighbor) {
        let waiting = n.queue
        n.queue = []
        for p in waiting { send(p, to: n.addr, on: n.iface) }
    }

    private func frame(_ p: Ipv6Packet, to mac: Mac, on iface: Interface) {
        node.sendFrame(iface, to: mac, etherType: ETHERTYPE_IPV6, .ipv6(p))
    }

    /// One more NS: to the solicited-node group while resolving, to the neighbour itself while probing. Its source is the waiting
    /// packet's when that is an address of the interface, else the interface's address of the target's scope (RFC 4861 §7.2.2).
    private func solicit(_ n: Neighbor) {
        n.solicits += 1
        n.due = arm(now + ND_RETRANS_NS)
        let usable = (n.iface.v6?.addrs ?? []).filter { $0.state == .preferred }
        let own = n.queue.first.map(\.src).flatMap { s in usable.contains { $0.addr == s } ? s : nil }
        guard let src = own ?? usable.first(where: { isLinkLocal6(n.addr) == ($0.origin == .linkLocal) })?.addr ?? usable.first?.addr else { return }
        let probing = n.state == .probe
        let dst = probing ? n.addr : solicitedNode(n.addr)
        let p = makeIpv6(src: src, dst: dst, hopLimit: 255, payload: .ndp(NdpMessage(body: .ns(target: n.addr, slla: n.iface.mac))))
        frame(p, to: probing ? n.mac! : multicastMac6(dst), on: n.iface)
    }

    private func arm(_ due: Int) -> Int {
        node.sim.sched.at(due) { [weak self] in self?.expire(due) }
        return due
    }

    private func expire(_ due: Int) {
        for n in entries where n.due == due {
            n.due = nil
            switch n.state {
            case .delay:
                n.state = .probe
                n.solicits = 0
                solicit(n)
            case .incomplete, .probe:
                if n.solicits < ND_MAX_SOLICIT {
                    solicit(n)
                    continue
                }
                entries.removeAll { $0 === n }
                for p in n.queue {
                    node.sim.emit(.drop, node: node.id, iface: n.iface.name, reason: .ndTimeout, packet6: p)
                    stack.error(p, type: ICMP6_DEST_UNREACH, code: UNREACH6_ADDRESS)
                }
            case .reachable, .stale:
                break
            }
        }
    }
}
```

```swift
        }
```

```swift
    /// SLAAC turned on solicits a router at once (spec M9 §5); turned off, its addresses go.
    func configure(_ name: String, _ config: Ipv6Config?) throws {
        let iface = try node.iface(name)
        guard let config else {
            iface.v6 = nil
            neighbors.forget(iface)
            defaults.removeAll { $0.iface === iface }
            return
```

```swift
    private func usableLinkLocal(_ iface: Interface) -> UInt128? {
        iface.v6?.addrs.first { $0.origin == .linkLocal && $0.state == .preferred }?.addr
    }

    /// IOS `ipv6 unicast-routing` on or off (spec M9 §5): on, every IPv6 interface advertises at once (from the scheduler); off,
    /// a last RA with lifetime 0 where RAs were sent.
    func setRouting(_ on: Bool) {
        guard on != routing else { return }
        routing = on
        for i in node.interfaces where i.v6 != nil {
            if on {
                i.v6!.raDue = arm(now)
            } else {
                if i.v6!.lastRa != nil { advertise(i, lifetime: 0) }
                i.v6!.raDue = nil
                i.v6!.lastRa = nil
            }
        }
    }

    /// A multicast RA with IOS defaults and the interface's global prefixes; the next one 200 s later (none after lifetime 0).
    private func advertise(_ iface: Interface, lifetime: UInt16 = RA_LIFETIME_S) {
        guard iface.lineUp, let ll = usableLinkLocal(iface) else {
            iface.v6?.raDue = nil
            return
        }
        let prefixes = iface.v6!.addrs.filter { $0.origin == .manual && $0.state != .duplicate }
            .map { PrefixInfo(prefix: networkOf6($0.addr, $0.prefix), length: $0.prefix) }
        sendNdp(.ra(RouterAdvert(lifetime: lifetime, slla: iface.mac, prefixes: prefixes)), src: ll, dst: ALL_NODES, on: iface)
        iface.v6!.lastRa = now
        iface.v6!.raDue = lifetime == 0 ? nil : arm(now + RA_INTERVAL_NS)
    }

    /// One RS to all routers; the next one after the current wait, which doubles up to 3600 s (RFC 7559).
    private func solicit(_ iface: Interface) {
        guard iface.lineUp, let ll = usableLinkLocal(iface) else {
            iface.v6?.rsDue = nil
            return
        }
        sendNdp(.rs(slla: iface.mac), src: ll, dst: ALL_ROUTERS, on: iface)
        iface.v6!.rsDue = arm(now + iface.v6!.rsInterval)
        iface.v6!.rsInterval = min(2 * iface.v6!.rsInterval, RS_MAX_INTERVAL_NS)
    }

    /// The link-local address passed DAD: a host looks for routers, a router that routes advertises.
    private func linkLocalReady(_ iface: Interface) {
        if node is Host {
            solicit(iface)
        } else if routing {
            advertise(iface)
        }
    }
```

```swift
    /// `ipv6 unicast-routing`, never with a link-local address (RFC 4291 §2.5.6) nor to one of its own tentative or duplicate ones.
    func input(_ p: Ipv6Packet, on iface: Interface) {
        guard iface.v6 != nil else { return } // IPv6 off: like an unknown EtherType
        if isMulticast6(p.dst) {
            if groups(iface).contains(p.dst) { deliver(p, on: iface) }
            return
        }
        if owns(p.dst) { return deliver(p, on: iface) }
        guard routing, !isLinkLocal6(p.src), !isLinkLocal6(p.dst),
              !node.interfaces.contains(where: { $0.v6?.addrs.contains { $0.addr == p.dst } == true }) else { return }
```

```swift
    /// The interface and next hop toward `dst` (spec M9 §6): longest prefix first; on equal prefixes connected (0) beats static
    /// (1), which beats the RA's default (2). A static route whose next hop is not reachable does not count.
    func lookup(_ dst: UInt128) -> NextHop6? {
        var best: NextHop6?
        var bestPrefix = -1
        for r in statics where inSubnet6(dst, r.network, r.prefix) && r.prefix > bestPrefix {
            guard let via = connected(r.nextHop) else { continue }
            best = NextHop6(iface: via.iface, nextHop: r.nextHop)
            bestPrefix = r.prefix
        }
        if best == nil, let r = defaults.first(where: { $0.expiresAt > now }) {
            best = NextHop6(iface: r.iface, nextHop: r.addr)
            bestPrefix = 0
        }
        if let c = connected(dst), c.prefix >= bestPrefix { return NextHop6(iface: c.iface, nextHop: dst) }
        return best
    }
```

```swift
    private func onIcmp(from: String, _ m: IcmpMessage) {
        let v6 = dst6 != nil
        let exceeded = v6 ? ICMP6_TIME_EXCEEDED : ICMP_TIME_EXCEEDED
        let unreach = v6 ? ICMP6_DEST_UNREACH : ICMP_DEST_UNREACH
        guard let flight = current, m.type == exceeded || m.type == unreach else { return }
        // Quoted datagram: the original IP header (IPv4 20 B, IPv6 40 B) + UDP header (8 B). Only our own probes count.
        let q = m.data
        let at = v6 ? 40 : 20
        guard q.count >= at + 8, q[v6 ? 6 : 9] == IPPROTO_UDP else { return }
        let ours: Bool
        if let dst6 {
            ours = Array(q[24..<40]) == bytes16(dst6)
        } else {
            let quotedDst = UInt32(q[16]) << 24 | UInt32(q[17]) << 16 | UInt32(q[18]) << 8 | UInt32(q[19])
            ours = quotedDst == dst
        }
        let quotedSrcPort = UInt16(q[at]) << 8 | UInt16(q[at + 1])
        guard ours, quotedSrcPort == srcPort else { return }
        let dport = UInt16(q[at + 2]) << 8 | UInt16(q[at + 3])
        guard let probe = flight.sent.removeValue(forKey: dport) else { return }
        let portUnreachable = v6 ? UNREACH6_PORT : UNREACH_PORT
        let note = m.type == unreach && m.code != portUnreachable ? (v6 ? NOTES6 : NOTES)[m.code] ?? "!<\(m.code)>" : nil
        result.hops[flight.hopIndex].probes[probe.index] = TraceProbe(from: from, rttNs: node.sim.now - probe.at, note: note)
        if m.type == unreach { result.reached = true }
        flight.pending -= 1
        if flight.pending == 0 { closeHop() }
    }
```
