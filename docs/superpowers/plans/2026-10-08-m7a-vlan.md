# M7a — VLAN 802.1Q and router-on-a-stick (Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Segment a LAN into VLANs: 802.1Q tags on the wire (+4 B, an "802.1Q" layer in the PDU inspector), switch ports in access or trunk mode with allowed list and native VLAN, a MAC table per VLAN, flooding confined to the VLAN, refused frames dropped with a reason, router subinterfaces `<physical>.<VLAN>` for router-on-a-stick, the Porte/Interfacce/Tabelle UI for them, the trunk cable label, persistence, and the duplicate-address check per broadcast domain.

**Architecture:** `PacEngine` gains `EthernetFrame.vlan`, a `Switchport` value on every `Interface` (only switches read it) that answers ingress, carries and tag questions, a `(VLAN, MAC)`-keyed MAC table in `Switch`, router subinterfaces as ordinary `Interface`s with a `dot1q` (parent, VLAN) that send through their physical interface tagged and receive by VLAN dispatch in `IpNode.receive`, and a VLAN-aware `segmentPeers()`. Three commands (`setSwitchport`, `addSubinterface`, `removeSubinterface`), `IfaceView.switchport`, `MacRow.vlan` and `TopologyIface.switchport` carry it to `PacKit`, whose `Editor` gets `setPort` (typed fields like `DhcpField`) and `addSubinterface`, plus `isTrunk` for the cable label. `PacTrack` draws the Porte fields, the MAC VLAN column, the subinterface form and the trunk label.

**Tech Stack:** Swift 6.3, SwiftUI + AppKit (macOS 15), Observation, Swift Testing, SwiftPM, Command Line Tools only — no Xcode.

**Spec:** `docs/superpowers/specs/2026-10-08-m7-vlan-stp-design.md` §2, §3, the VLAN parts of §5, §6 and §7 (milestone M7a), extending `docs/superpowers/specs/2026-10-07-pac-track-rewrite-design.md` (rev. 2), whose rules on engine, determinism, UI, persistence and errors still apply. Conventions: `docs/superpowers/plans/2026-10-08-m6-polish-packaging.md`; rulings ledger style: `.superpowers/sdd/2026-10-08-m6-polish-packaging/progress.md`. ## Rulings (where the spec is silent)

Each line: ruling — why — cost if wrong.

- A subinterface's number is its VLAN: the form asks for physical interface, VID and address and creates `<physical>.<VID>`; "duplicate VID on the same physical interface" and "subinterface name in use" are one error, `Gi0/0.10 already exists`; `.ptk` stores no separate VID — the spec's form has no number field and it is the usual lab convention — an IOS config with `Gi0/0.100` + `encapsulation dot1q 10` must be renumbered.
- No `encapsulation dot1q N native`: untagged frames belong to the physical interface and its own address (spec §3) — as written in the spec — a lab wanting the native VLAN on a subinterface uses the physical interface.
- Subinterfaces only on `kind == .router` (not on a Cloud, a subclass of `Router`) — spec §6 "dispositivo che non è un router" — none.
- A subinterface cannot be cabled (`Cannot cable a subinterface`) and shows as linked when its physical interface is; its power and link state are the physical interface's — IOS — none.
- Deleting a subinterface is refused while a NAT role or a firewall rule names it (`Gi0/0.10 has a NAT role`, `… has firewall rules`), like a smaller switch refusing connected ports; IOS drops those bindings with the interface — keeps the saved NAT/firewall config loadable without cascade code — one extra click to clear the role first.
- Adding a subinterface with an address is one undo step; if the address is refused the subinterface stays without it and the error shows under the form (IOS creates the interface and rejects the `ip address` line) — no rollback code — the user types the address in the subinterface's own field.
- Access port + tagged frame: dropped `vlan-not-allowed` even when the tag equals the access VLAN (some Catalysts accept it) — spec §2 "lo stesso vale" — none.
- A trunk accepts frames tagged with its native VLAN and sends the native VLAN untagged (IOS without `vlan dot1q tag native`) — IOS — none.
- The native VLAN must be in the allowed list (spec error "nativa non ammessa"); all fields are validated whatever the mode and keep their values when the mode flips (IOS keeps trunk settings on an access port) — simple and order-independent — the user sets the native VLAN before narrowing the list.
- Allowed list: `all` or `10,20,30-35`, spaces ignored, saved as typed (trimmed), never rewritten; empty is invalid (no `none`) — IOS syntax — two spellings of one list are two different saved texts.
- Changing a port's VLAN settings flushes the MAC entries learned on that port (IOS) and is never refused for duplicate addresses, like cabling — consistent with the M6 duplicate rule — a duplicate made by moving a port to another VLAN shows only as ARP confusion.
- Drop reasons: `vlan-not-allowed` at a switch port (ingress), `unknown-vlan` at a host or router (no subinterface for the tag). An end node filters by MAC first (NIC hardware), so only frames addressed to it or broadcast produce `unknown-vlan` — informative without flooding the list — none.
- Frame sizes: the tag adds 4 B to `size`; the minimum stays 64 B on the wire (802.3 pads untagged frames to 64 and bridges tag them as they are) — 802.1Q — a tagged ARP shows the same 84 wire bytes as an untagged one.
- PDU inspector: Ethernet II shows `EtherType 0x8100 (802.1Q)`; a separate *802.1Q* layer of 4 B shows PCP 0, DEI 0, VLAN ID and the payload's EtherType — Wireshark's layout — none.
- The cable label says `trunk` when either end is a switch port in trunk mode (router ends have no mode) — spec §5 — a router with subinterfaces on an access port is not labelled.
- Copies (duplicate/paste) keep port VLAN settings and subinterfaces, not addresses — structure, like the switch size M6 already copies — none.
- The duplicate-address domain follows VLANs: access ports, a trunk's allowed list and native VLAN, subinterfaces; hubs pass tags as they are — spec §6 "segmento = dominio di broadcast" — none.
- ARP entries learned on a deleted subinterface age out normally, as when an address is cleared today — existing behaviour — up to 300 s of stale rows in Cache ARP.
- M7b: `Switchport` (`ingress`/`carries`/`tag`) is the single place a per-VLAN port state will gate forwarding, and `MAC_AGING_NS` is read only in `Switch.lookup`; nothing in M7a makes PVST+ harder.

```swift
struct EthernetFrame: Equatable, Sendable {
    var id: Int
    var src: Mac
    var dst: Mac
    var etherType: UInt16
    var payload: L3
    /// 802.1Q tag (TPID 0x8100, PCP and DEI 0): the VLAN ID; nil while the frame travels untagged.
    var vlan: Int? = nil

    /// Size as shown by Wireshark: Ethernet header (+ 4 B with a tag) + payload, no FCS.
    var size: Int {
        let header = vlan == nil ? 14 : 18
        switch payload {
        case .arp: return header + 28
        case .ipv4(let p): return header + p.size
        }
    }

    /// Bytes occupying the wire: frame + FCS padded to 64, plus preamble/SFD (8) and inter-frame gap (12). A tag does not raise
    /// the 64-byte minimum (frames are padded untagged and bridges tag them as they are).
    var wireBytes: Int { max(size + 4, 64) + 20 }
}
```

@testable import PacEngine

/// Probes on the switch's first ports, in order.
private func probes(_ sim: Sim, _ sw: Switch, _ names: [String]) throws -> [Probe] {
    try names.enumerated().map { i, name in
        let p = Probe(sim: sim, id: name)
        _ = try Link(sim: sim, try p.iface("eth0"), sw.interfaces[i])
        return p
    }
}

private func cable(_ rt: Runtime, _ id: String, _ a: String, _ ai: String, _ b: String, _ bi: String) throws {
    try rt.handle(.connect(id: id, a: IfaceRef(node: a, iface: ai), b: IfaceRef(node: b, iface: bi)))
}

private func runFor(_ rt: Runtime, wallMs: Int) {
    for _ in stride(from: 0, to: wallMs, by: 100) { rt.advance(wallMs: 100) }
}

/// VLAN IDs a port or a subinterface may use: 0 and 4095 are reserved (802.1Q).
let VLAN_IDS = 1...4094

func checkVlan(_ vlan: Int) throws {
    guard VLAN_IDS.contains(vlan) else { throw EngineError("VLAN must be between 1 and 4094") }
}

/// IOS `switchport trunk allowed vlan` syntax: "all" or "10,20,30-35" (spaces ignored).
func parseVlanList(_ text: String) throws -> [ClosedRange<Int>] {
    let t = String(text.filter { !$0.isWhitespace })
    if t.lowercased() == "all" { return [VLAN_IDS] }
    return try t.split(separator: ",", omittingEmptySubsequences: false).map { item in
        let ends = item.split(separator: "-", omittingEmptySubsequences: false).map { Int($0) }
        guard (1...2).contains(ends.count), let lo = ends[0], let hi = ends[ends.count - 1], lo <= hi else {
            throw EngineError("Invalid VLAN list: \"\(text)\"")
        }
        try checkVlan(lo)
        try checkVlan(hi)
        return lo...hi
    }
}

/// A switch port's 802.1Q role (spec M7 §2): an access port carries one VLAN, untagged; a trunk carries its allowed VLANs,
/// tagged, except the native one, untagged.
struct Switchport {
    private(set) var config = PortConfig()
    /// The VLANs a trunk carries, parsed from `config.allowed`.
    private var allowed = [VLAN_IDS]

    init() {}

    /// Checks every field, whatever the mode (the fields keep their values when the mode flips, as on IOS).
    init(_ c: PortConfig) throws {
        try checkVlan(c.vlan)
        try checkVlan(c.native)
        let allowed = try parseVlanList(c.allowed)
        guard allowed.contains(where: { $0.contains(c.native) }) else { throw EngineError("Native VLAN \(c.native) is not allowed on the trunk") }
        config = c
        self.allowed = allowed
    }

    func carries(_ vlan: Int) -> Bool {
        config.mode == .access ? vlan == config.vlan : allowed.contains { $0.contains(vlan) }
    }

    /// The VLAN of a frame arriving with `tag`; nil when the port refuses it: tagged on an access port, or a VLAN the trunk does not carry.
    func ingress(_ tag: Int?) -> Int? {
        guard let tag else { return config.mode == .access ? config.vlan : config.native }
        return config.mode == .trunk && carries(tag) ? tag : nil
    }

    /// The tag a frame of `vlan` leaves with: none on an access port and for the trunk's native VLAN.
    func tag(_ vlan: Int) -> Int? {
        config.mode == .trunk && vlan != config.native ? vlan : nil
    }
}

```swift
/// A MAC table key: one address can sit in several VLANs (a router-on-a-stick's MAC is in all of them).
private struct MacKey: Hashable {
    let vlan: Int
    let mac: Mac
}

/// Transparent learning bridge with 802.1Q VLANs (802.1D without STP): one MAC table per VLAN, flooding confined to the frame's VLAN.
final class Switch: Node {
    private var table: [MacKey: (iface: Interface, seen: Int)] = [:]

    init(sim: Sim, id: String, ports: Int = 8) {
        super.init(sim: sim, id: id)
        for i in 1...ports { addInterface("Gi0/\(i)") }
    }

    /// 8, 24 or 48 ports (spec §5.5); the ports taken away must be free.
    func setPorts(_ count: Int) throws {
        guard SWITCH_PORTS.contains(count) else { throw EngineError("A switch has 8, 24 or 48 ports") }
        if let busy = interfaces.dropFirst(count).first(where: { $0.link != nil }) { throw EngineError("\(busy.name) is connected") }
        while interfaces.count > count { removeLastInterface() }
        while interfaces.count < count { addInterface("Gi0/\(interfaces.count + 1)") }
        table = table.filter { entry in interfaces.contains { $0 === entry.value.iface } }
    }

    /// IOS `switchport mode access|trunk` with its VLANs; the addresses the port learned are flushed, as IOS does on a VLAN change.
    func setSwitchport(_ name: String, _ c: PortConfig) throws {
        let port = try iface(name)
        port.switchport = try Switchport(c)
        table = table.filter { $0.value.iface !== port }
    }

    func lookup(_ mac: Mac, vlan: Int) -> Interface? {
        let key = MacKey(vlan: vlan, mac: mac)
        guard let entry = table[key] else { return nil }
        if sim.now - entry.seen > MAC_AGING_NS {
            table[key] = nil
            return nil
        }
        return entry.iface
    }

    /// By VLAN, then MAC.
    func macTable() -> [(vlan: Int, mac: Mac, iface: String, ageNs: Int)] {
        table.keys.sorted { ($0.vlan, $0.mac) < ($1.vlan, $1.mac) }.compactMap { key in
            guard let iface = lookup(key.mac, vlan: key.vlan), let seen = table[key]?.seen else { return nil }
            return (key.vlan, key.mac, iface.name, sim.now - seen)
        }
    }

    override func reset() {
        table = [:]
    }

    override func receive(_ frame: EthernetFrame, on inIf: Interface) {
        sim.noteL2(frame, at: id)
        guard let vlan = inIf.switchport.ingress(frame.vlan) else {
            sim.emit(.drop, node: id, iface: inIf.name, frame: frame, reason: .vlanNotAllowed)
            return
        }
        if !isGroupMac(frame.src) { table[MacKey(vlan: vlan, mac: frame.src)] = (inIf, sim.now) }
        if !isGroupMac(frame.dst), let out = lookup(frame.dst, vlan: vlan) {
            if out !== inIf { forward(frame, vlan, to: out) }
            return
        }
        for i in interfaces where i !== inIf && i.link != nil && i.switchport.carries(vlan) { forward(frame, vlan, to: i) }
    }

    /// Out of `port` in `vlan`: tagged on a trunk unless `vlan` is its native one.
    private func forward(_ frame: EthernetFrame, _ vlan: Int, to port: Interface) {
        var out = frame
        out.vlan = port.switchport.tag(vlan)
        port.send(out)
    }
}

    /// shares the physical interface's MAC, sends through it tagged, and is listed after it by VLAN.
    func addSubinterface(_ name: String) throws {
        let parts = name.split(separator: ".", omittingEmptySubsequences: false)
        guard parts.count == 2, let vlan = Int(parts[1]) else { throw EngineError("Invalid subinterface name: \"\(name)\"") }
        let parent = try iface(String(parts[0]))
        try checkVlan(vlan)
        let canonical = "\(parent.name).\(vlan)"
        guard !interfaces.contains(where: { $0.name == canonical }) else { throw EngineError("\(canonical) already exists") }
        // The physical interface itself matches (VLAN 0), so the index always exists.

        if firewall?.config.rules.contains(where: { $0.iface == name }) == true { throw EngineError("\(name) has firewall rules") }

extension Interface {
    /// IP interfaces in this interface's broadcast domain: across cables, hubs and switches within one VLAN (access ports, a trunk's
    /// allowed and native VLANs, subinterfaces), whatever their power or link state; self excluded.
    func segmentPeers() -> [Interface] {
        /// An interface reached by a frame carrying `tag` on the wire.
        struct Hop: Hashable {
            let iface: ObjectIdentifier
            let tag: Int?
        }
        // A subinterface's frames leave its physical interface tagged.
        let start = (iface: dot1q?.parent ?? self, tag: dot1q?.vlan)
        var seen: Set<Hop> = [Hop(iface: ObjectIdentifier(start.iface), tag: start.tag)]
        var todo = [start]
        var peers: [Interface] = []
        while let hop = todo.popLast() {
            guard let peer = hop.iface.link?.peer(hop.iface), seen.insert(Hop(iface: ObjectIdentifier(peer), tag: hop.tag)).inserted else { continue }
            if peer.node is IpNode {
                // Untagged: the physical interface; tagged: its subinterface for that VLAN, if any.
                let ip = peer.node.interfaces.first { hop.tag == nil ? $0 === peer : $0.dot1q?.parent === peer && $0.dot1q?.vlan == hop.tag }
                if let ip { peers.append(ip) }
            } else if peer.node is Switch {
                guard let vlan = peer.switchport.ingress(hop.tag) else { continue }
                for next in peer.node.interfaces where next !== peer && next.switchport.carries(vlan) {
                    todo.append((next, next.switchport.tag(vlan)))
                }
            } else {
                for next in peer.node.interfaces where next !== peer { todo.append((next, hop.tag)) }
            }
        }
        return peers
    }
}
```

/// One switch-port VLAN setting typed in the Porte tab.
public enum PortField: String, Sendable {
    case vlan, allowed, native

    public var label: String {
        switch self {
        case .vlan: "VLAN"
        case .allowed: "VLAN ammesse"
        case .native: "Nativa"
        }
    }

    public func format(_ c: PortConfig) -> String {
        switch self {
        case .vlan: String(c.vlan)
        case .allowed: c.allowed
        case .native: String(c.native)
        }
    }

    /// Puts the typed text into the settings; the engine checks the ranges, the list and the native VLAN.
    public func apply(_ text: String, to c: PortConfig) throws -> PortConfig {
        let t = text.trimmingCharacters(in: .whitespaces)
        var n = c
        if self == .allowed {
            n.allowed = t
            return n
        }
        guard let v = Int(t) else { throw EngineError("Invalid number: \"\(text)\"") }
        if self == .vlan { n.vlan = v } else { n.native = v }
        return n
    }
}

/// True when either end of the cable is a switch port in trunk mode: its label says "trunk".
public func isTrunk(_ link: LinkView, in nodes: [NodeView]) -> Bool {
    [link.a, link.b].contains { end in
        nodes.first { $0.id == end.node }?.ifaces.first { $0.name == end.iface }?.switchport?.mode == .trunk
    }
}

    /// The Interfacce tab's "Aggiungi sottointerfaccia": `<parent>.<VLAN>` and its address (blank: none) in one undo step. A refused
    /// address leaves the subinterface without it, as IOS takes the interface and rejects the `ip address` line. Returns false, with
    /// the error under the form, if anything was refused.
    @discardableResult
    public func addSubinterface(_ id: String, parent: String, vlan: String, cidr: String) async -> Bool {
        await serialized {
            let key = "sub:\(id)"
            guard let v = Int(vlan.trimmingCharacters(in: .whitespaces)) else {
                self.error = EditorError(key: key, message: "Invalid number: \"\(vlan)\"")
                return false
            }
            let name = "\(parent).\(v)"
            let ip = cidr.trimmingCharacters(in: .whitespaces)
            var cmds: [Command] = [.addSubinterface(node: id, iface: name)]
            if !ip.isEmpty { cmds.append(.setIp(node: id, iface: name, cidr: ip)) }
            return await self.editNow(cmds, key: key)
        }
    }
