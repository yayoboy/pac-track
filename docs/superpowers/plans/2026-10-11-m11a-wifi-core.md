# M11a — Wi-Fi core: access point, wireless hosts, radio medium, association (Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Wi-Fi network works frame by frame like a cabled one (spec M11 §1, success M11a): clients scan with Probe Requests on channels 1, 6, 11, authenticate (Open System) and associate with an *Access point*, take their address from DHCP through it, and ping, DNS and traffic cross the air with the 802.11 header and LLC/SNAP over one shared half-duplex medium with 802.11g timing; a dashed line joins each client to its access point.

**Architecture:**
- `EthernetFrame.air: Dot11Header?` is the 802.11 MAC header while a frame is on the air (set by the transmitting radio, cleared by the access point when it bridges to Ethernet); `L3.mgmt(Dot11Mgmt)` carries the management frames. Airtime and sizes are pure functions in `PDU.swift`.
- `Medium` (one per channel, owned by the `Sim`, made lazily) serves frames FIFO across every radio on its channel: DIFS + backoff + PPDU, then SIFS + ACK for unicast. `Radio` (base) has two subclasses: `StationRadio` (scan → authenticate → associate, generation-guarded timers like `DhcpClient`) and `ApRadio` (probes, authentication, association table by AID). `Interface.radio` routes `Interface.send` through the radio.
- `AccessPoint: Node` bridges `Gi0` and `Dot11Radio0` (spec §6). `Host(sim:id:wifi:)` has one card, `eth0` or `wlan0`; tablets and smartphones are Wi-Fi hosts; `Host.setStation` swaps a PC's or laptop's card. On Wi-Fi, `lineUp` is the association and DHCP runs only while associated.
- Commands `.setAccessPoint`, `.setStation`; snapshot `IfaceView.wireless`, `NodeView.accessPoint`, `NodeView.station`; `TopologyNode.accessPoint`, `.station`. PacKit: kinds' labels and tabs, editor defaults, card swap, copies, `airLinks` for the dashed lines and the flights. PacTrack: palette section *Wireless*, Wi-Fi tab, Tabelle rows, dashed lines, two-row event filters with the *802.11* chip, M11a selftest.

**Tech Stack:** Swift 6.3, SwiftUI + AppKit (macOS 15), Observation, Swift Testing, SwiftPM, Command Line Tools only — no Xcode.

**Spec:** `docs/superpowers/specs/2026-10-11-m11-wifi-design.md` — M11a only: §1 (success M11a), §2–§7, §9–§11. §8 (M11b) is **not** planned. It extends `docs/superpowers/specs/2026-10-07-pac-track-rewrite-design.md` (rev. 2) and M7–M10.

## Review Focus

1. **Cables behave as before.** `Interface.send`, `lineUp`, `segmentPeers` and `Host` change for Wi-Fi only: on a cable DHCP still starts at power-on (M3) and a card swap is the only way an interface changes. Pinned by the full suite (DhcpTests, DuplicateAddressTests, RuntimeTests unchanged) and `dhcpAndDadStartAtAssociationAndDhcpStopsWhenItEnds` (Task 3).
2. **Power and removal in the middle of an exchange.** An access point or a station switched off or removed while frames wait for the medium: queued frames drop `iface-down`, a frame in the air from a forgotten station drops `not-associated` at the AP, the other side drops the association at once, nothing crashes. Pinned by `switchingEitherSideOffEndsTheAssociationAtOnce` (Task 2), `aRadioQueuesAtMost1000FramesAndLosesThemWhenSwitchedOff` (Task 3), the `removeNode` check in `accessPointsTabletsAndSmartphonesAndTheirWifiSettings` (Task 4).
3. **Same seed, same air.** Two runs of the same network give the same event log (FIFO medium, radios in device order, no dictionary iteration). Pinned by `stationsGetAidsInTheOrderTheyAssociateAndRunsRepeat` (Task 2).
4. **Group frames do not loop or echo.** A station's broadcast goes once to the cable and once back on the air (From DS), never back to its sender; a frame from the cable is never sent back to the cable; BPDUs stop at the AP. Pinned by `theAccessPointBridgesToTheCableAndRelaysGroupFrames` and `theAccessPointNeitherRunsNorRelaysSpanningTreeAndDropsTaggedFrames` (Task 3).
5. **What the learner reads.** SSIDs counted in UTF-8 bytes (17 × "è" is refused), the error under the SSID field, every event chip visible with *802.11* after *NDP*, the dashed lines in the PNG export. ## Rulings (where the spec is silent, or where the code refines the coordinator's architecture)

Each line gives the ruling, why, and the cost if wrong.

- **ERP-OFDM adds the 6 µs signal extension** to every PPDU (802.11-2016 §18, aSignalExtension), so an ACK is 34 µs and the Duration field 44 µs (what 2.4 GHz captures show). Spec §4 lists preamble, symbols and tail only. Why: fidelity; it brings the 1470-byte UDP frame to 389 µs (spec: "~387 µs") and 30.2 Mb/s. Cost if wrong: 12 µs per unicast frame.
- **TX is logged when a frame takes the medium** (DIFS and backoff are its own wait), **RX when it ends**; the medium stays busy for SIFS + ACK after the RX. Why: one scheduled event per frame, like `Link`. Cost if wrong: TX times 91 µs early.
- **`Radio` is a base class with `StationRadio` and `ApRadio`** (coordinator: one radio with two roles). Why: two different state machines; the medium only needs `hears`, `receive`, `bssid`. Cost if wrong: none.
- **The access point's default network is the engine's** (`ApConfig()` = `pac-track`, channel 6), so `.setAccessPoint` takes a non-optional config and the editor sends no default for an AP. Why: an AP without an SSID has no meaning; a saved AP always has its `accessPoint` key. Cost if wrong: none.
- **The address filter also drops a group frame whose source is the radio itself** (spec §6: "il mittente lo riconosce come suo dalla sorgente e lo ignora"): no RX event at the original sender. Why: an RX that is thrown away teaches nothing and doubles events. Cost if wrong: one event per broadcast.
- **DHCP on Wi-Fi runs only while associated:** `start()` at association, `stop(release: false)` (address gone) when it ends, like NetworkManager. Why: spec §5 starts it at association; keeping a lease without a link would retransmit into `not-associated` drops. Cost if wrong: the address disappears while the AP is off.
- **`StationState.notFound`** between a scan nobody answered and the rescan (spec §7: "Nessuna rete trovata"). Cost if wrong: none.
- **Association Request listen interval 10**, AID shown with its two high bits (0xc001, §9.4.1.8). Why: common client value. Cost if wrong: a field value.
- **The AP answers only Probe Requests carrying its SSID and keeps no per-station authentication state** (`ponytail:` comment). Why: the stations here always send their SSID and authenticate before associating. Cost if wrong: an unauthenticated association request would be accepted.
- **Data reaching an AP from a station it does not know is dropped `not-associated` there.** Why: frames already queued when the AP forgot a station. Cost if wrong: one drop line.
- **A timeout in authentication or association restarts the scan through `restart()`**, which bumps the generation like every state change.
- **Sequence numbers start at 0 per radio and are taken when a frame is handed to the medium.**
- **`IfaceView.linked` means "associated" on a wireless interface** (on the AP's radio: at least one client), so the node's dot turns green; `firstFreeIface` skips wireless interfaces, so a cable from a tablet gets the existing "has no free port" error.
- **`Host.nic` is the host's only interface**, `Host.station` its radio when Wi-Fi; `Host.setDhcp` uses `nic` instead of `"eth0"`.
- **A card swap goes silently** (no DHCP RELEASE, no Deauthentication: the card is gone) and is refused with `"eth0 is connected"`; a tablet or smartphone refuses `nil` with `"TAB1 has only a Wi-Fi card"`, other kinds `"PRN1 cannot use Wi-Fi"`, and `.setAccessPoint` on another kind `"PRN1 is not an access point"`. SSID errors: `"SSID must be 1 to 32 bytes"` (AP), `"SSID must be at most 32 bytes"` (client); channel `"Channel must be 1, 6 or 11"`.
- **`WIFI_CHANNELS = [1, 6, 11]` is public** (engine scan order and validation, UI channel picker).
- **Air links are `LinkView`s with id `"air:<station id>"`** from `airLinks(_:)`, never in `snapshot.links`. A frame from the AP's radio is drawn when a station receives it (the radio reaches several stations), a station's frame when it leaves. Cost if wrong: an animation starts a few µs late.
- **Icons:** access point `antenna.radiowaves.left.and.right` (the router already uses `wifi.router`), tablet `ipad`, smartphone `iphone` (SF Symbols 2+, on macOS 15). Name prefixes `AP`, `TAB`, `PHONE`.
- **The *802.11* chip comes after NDP** (`Proto.wifi`, raw value `wifi`, colour 0xC4C9D4, silver, unlike every other chip).
- **The Wireless section also answers to `wifi`, `wi-fi`, `ap`** (a per-section alias string in `PaletteView`).
- **Task 4 gives the new kinds their tabs without Wi-Fi; Task 6 adds `InspectorTab.wifi`** with its view. Why: the enum case forces the view; each task stays green. Cost if wrong: one test line changes in Task 6.
- **The spec lab turns SRV1's sink on before the UDP generator** (spec §1 leaves it implicit: the generator measures what the sink receives).

    EthernetFrame(id: 1, src: src, dst: dst, etherType: 0, payload: .mgmt(m), air: Dot11Header(bssid: bssid))

/// A 56-byte ping from STA to DST, To DS or relayed From DS by AP.
private func echo(toDS: Bool) -> EthernetFrame {
    let p = makeIpv4(src: 1, dst: 2, ttl: 64, id: 1,
                     payload: .icmp(makeIcmp(type: ICMP_ECHO_REQUEST, code: 0, id: 1, seq: 1, data: [UInt8](repeating: 0, count: 56))))

/// that bridges it to Ethernet. The frame keeps its Ethernet source and destination; address 1–3 follow from them and the direction.

    var toDS = false
    var fromDS = false
    /// The access point's radio MAC; broadcast (the wildcard BSSID) in a Probe Request.
    var bssid: Mac
    /// 12-bit sequence number of the transmitter (§9.2.4.4); fragment 0.
    var seq = 0

    case probeRequest(ssid: String)
    /// `timestamp`: the access point's clock in µs.
    case probeResponse(ssid: String, channel: Int, timestamp: Int)
    /// Open System (algorithm 0): transaction 1 from the station, 2 with the status from the access point.
    case authentication(seq: Int, status: Int)
    case associationRequest(ssid: String)
    case associationResponse(status: Int, aid: Int)
    case deauthentication(reason: Int)

    var subtype: Int {
        switch self {
        case .associationRequest: 0
        case .associationResponse: 1
        case .probeRequest: 4
        case .probeResponse: 5
        case .authentication: 11
        case .deauthentication: 12
        }
    }

        case .probeRequest: "Probe Request"
        case .probeResponse: "Probe Response"
        case .authentication: "Authentication"
        case .associationRequest: "Association Request"
        case .associationResponse: "Association Response"
        case .deauthentication: "Deauthentication"
        }
    }

    /// Body: fixed fields, then the SSID (2 + length), Supported Rates (2 + 8) and DS Parameter Set (2 + 1) elements (§9.3.3.6–13).
    var size: Int {
        switch self {
        case .probeRequest(let ssid): 2 + ssid.utf8.count + 10
        case .probeResponse(let ssid, _, _): 8 + 2 + 2 + 2 + ssid.utf8.count + 10 + 3

        case .associationRequest(let ssid): 2 + 2 + 2 + ssid.utf8.count + 10
        case .associationResponse: 2 + 2 + 2 + 10
        case .deauthentication: 2
        }

/// µs on the air of a PPDU carrying `bytes` of MAC frame with its FCS (§17.4.3 and §18): preamble and SIGNAL (20 µs), 4 µs symbols of
/// 4 × rate data bits for the 16 SERVICE bits, the frame and the 6 tail bits, then the ERP signal extension.
func dot11TxUs(bytes: Int, rateMbps: Int) -> Int {
    let bits = 16 + 8 * bytes + 6
    let perSymbol = 4 * rateMbps
    return 20 + 4 * ((bits + perSymbol - 1) / perSymbol) + DOT11_SIGNAL_EXTENSION_US
}

/// The medium's time for one frame (spec M11 §4): DIFS, backoff and the PPDU until it is received, then SIFS + ACK for a unicast
/// one (its Duration field). Unicast data goes at 54 Mb/s, management and group frames at 6.
func dot11Airtime(_ f: EthernetFrame) -> (frame: Int, ack: Int) {
    let group = isGroupMac(f.receiver)
    let mgmt = if case .mgmt = f.payload { true } else { false }
    let rate = mgmt || group ? DOT11_BASIC_RATE : DOT11_DATA_RATE
    return (DOT11_DIFS_US + DOT11_BACKOFF_US + dot11TxUs(bytes: f.size + 4, rateMbps: rate), group ? 0 : DOT11_ACK_US)
}

/// The 802.11 MAC header (spec M11 §3): type and subtype by name, flags, Duration, the three addresses with their roles, sequence.
private func dot11Layer(_ f: EthernetFrame, _ h: Dot11Header) -> PduLayer {
    let (type, subtype) = if case .mgmt(let m) = f.payload { ("0 (gestione)", "\(m.subtype) (\(m.name))") } else { ("2 (dati)", "0 (Data)") }
    let addresses: [(String, Mac)] = h.toDS ? [("ricevitore, BSSID", h.bssid), ("trasmettitore, sorgente", f.src), ("destinazione", f.dst)]
        : h.fromDS ? [("ricevitore, destinazione", f.dst), ("trasmettitore, BSSID", h.bssid), ("sorgente", f.src)]
        : [("ricevitore, destinazione", f.dst), ("trasmettitore, sorgente", f.src), ("BSSID", h.bssid)]
    return PduLayer(title: "IEEE 802.11", bytes: f.size, fields: [
        field("Versione", "0"),
        field("Tipo", type),
        field("Sottotipo", subtype),
        field("Flag", h.toDS ? "0x01 (To DS)" : h.fromDS ? "0x02 (From DS)" : "0x00"),
        field("Duration", "\(dot11Airtime(f).ack) µs"),
    ] + addresses.enumerated().map { field("Indirizzo \($0.offset + 1) (\($0.element.0))", $0.element.1) }
      + [field("Numero di sequenza", "\(h.seq)"), field("Frammento", "0")])
}

/// RFC 1042 encapsulation of a packet on the air.
private func llcSnapLayer(_ etherType: UInt16) -> PduLayer {
    PduLayer(title: "LLC/SNAP", bytes: 8, fields: [
        field("DSAP", "0xaa (SNAP)"),
        field("SSAP", "0xaa (SNAP)"),
        field("Controllo", "0x03 (UI)"),
        field("OUI", "0x000000 (RFC 1042)"),
        field("EtherType", etherTypeText(etherType)),
    ])
}

/// A management body (§9.3.3), field by field.
private func mgmtLayer(_ m: Dot11Mgmt) -> PduLayer {
    let rates = DOT11_RATES.map { DOT11_BASIC_RATES.contains($0) ? "\($0)(B)" : "\($0)" }.joined(separator: ", ") + " Mb/s"
    let status = { (s: Int) in s == 0 ? "0 (successo)" : "\(s)" }
    let capability = field("Capability", hex(DOT11_CAPABILITY, digits: 4) + " (ESS, short slot)")
    let fields: [PduField] = switch m {
    case .probeRequest(let ssid): [field("SSID", ssid), field("Velocità supportate", rates)]
    case .probeResponse(let ssid, let channel, let timestamp):
        [field("Timestamp", "\(timestamp) µs"), field("Intervallo di beacon", "\(DOT11_BEACON_TU) TU (102.4 ms)"), capability,
         field("SSID", ssid), field("Velocità supportate", rates), field("Canale (DS Parameter Set)", "\(channel)")]
    case .authentication(let seq, let s): [field("Algoritmo", "0 (Open System)"), field("Numero di transazione", "\(seq)"), field("Stato", status(s))]
    case .associationRequest(let ssid):
        [capability, field("Intervallo di ascolto", "\(DOT11_LISTEN_INTERVAL)"), field("SSID", ssid), field("Velocità supportate", rates)]
    case .associationResponse(let s, let aid):
        // The AID field carries the two high bits set (§9.4.1.8).
        [capability, field("Stato", status(s)), field("AID", "\(aid) (\(hex(0xC000 | aid, digits: 4)))"), field("Velocità supportate", rates)]
    case .deauthentication(let reason): [field("Motivo", reason == DOT11_REASON_LEAVING ? "3 (lascia il BSS)" : "\(reason)")]
    }
    return PduLayer(title: "Gestione 802.11", bytes: m.size, fields: fields)
}

/// Active scanning and association (spec M11 §5): 20 ms on each channel, a new scan 5 s after one nobody answered, 1 s for each
/// answer of the access point before starting over.
let SCAN_DWELL_NS = 20 * MS
let RESCAN_NS = 5 * S
let DOT11_TIMEOUT_NS = 1 * S

/// An SSID is at most 32 bytes (IEEE 802.11-2016 §9.4.2.2); an access point's is never empty.
func checkSsid(_ ssid: String, empty: Bool) throws {
    guard ssid.utf8.count <= 32, empty || !ssid.isEmpty else {
        throw EngineError(empty ? "SSID must be at most 32 bytes" : "SSID must be 1 to 32 bytes")
    }
}

/// One 2.4 GHz channel (spec M11 §4): a half-duplex medium shared by every radio tuned to it. One frame at a time, served in order of
/// arrival (a CSMA/CA that never collides); each holds it for DIFS + backoff + the frame, then SIFS + ACK if unicast.
final class Medium {
    unowned let sim: Sim
    let channel: Int
    private var queue: [(radio: Radio, frame: EthernetFrame)] = []
    private var busy = false

    init(sim: Sim, channel: Int) {
        self.sim = sim
        self.channel = channel
    }

    /// On the air at once if the medium is free, else in the queue (at most DOT11_QUEUE_LIMIT frames per radio).
    func transmit(_ frame: EthernetFrame, from radio: Radio) {
        guard busy else { return start(frame, from: radio) }
        guard radio.queued < DOT11_QUEUE_LIMIT else {
            return sim.emit(.drop, node: radio.iface.node.id, iface: radio.iface.name, frame: frame, reason: .queueFull)
        }
        radio.queued += 1
        queue.append((radio, frame))
    }

    /// TX when the frame takes the medium, RX at every radio of the channel that is on and addressed when it ends (the others drop it
    /// silently, like a card's MAC filter); the ACK keeps the medium busy after that.
    private func start(_ frame: EthernetFrame, from radio: Radio) {
        busy = true
        sim.emit(.tx, node: radio.iface.node.id, iface: radio.iface.name, frame: frame)
        let t = dot11Airtime(frame)
        sim.sched.after(t.frame * US) { [self] in
            for r in sim.radios() where r !== radio && r.channel == channel && r.iface.node.powered && r.hears(frame) {
                sim.emit(.rx, node: r.iface.node.id, iface: r.iface.name, frame: frame)
                r.receive(frame, from: radio)
            }
            sim.sched.after(t.ack * US) { [self] in next() }
        }
    }

    private func next() {
        while !queue.isEmpty {
            let (radio, frame) = queue.removeFirst()
            radio.queued -= 1
            if radio.iface.node.powered { return start(frame, from: radio) }
            // A radio switched off loses what was waiting, and says so (like a cable's queue).
            sim.emit(.drop, node: radio.iface.node.id, iface: radio.iface.name, frame: frame, reason: .ifaceDown)
        }
        busy = false
    }
}

/// A Wi-Fi interface's radio (spec M11 §4): it puts frames on its channel's medium with an 802.11 header and hears, of what goes by,
/// only what is addressed to it. Subclasses override `receive`.
class Radio {
    unowned let iface: Interface
    /// The channel it is tuned to.
    var channel: Int
    /// Its frames waiting for the medium.
    var queued = 0
    /// The next sequence number: 12 bits, one counter per transmitter (§9.2.4.4).
    private var seq = 0

    init(iface: Interface, channel: Int) {
        self.iface = iface
        self.channel = channel
    }

    var sim: Sim { iface.node.sim }
    /// Its BSS: an access point's own MAC, a station's chosen access point.
    var bssid: Mac? { nil }
    /// What `Interface.lineUp` reports: a station associated, an access point with stations.
    var lineUp: Bool { false }

    func receive(_ f: EthernetFrame, from sender: Radio) {
        fatalError("\(type(of: self)) must override receive(_:from:)")
    }

    /// The address filter (spec M11 §4): frames to its own MAC, and group frames of its BSS (for an access point: the Probe Requests,
    /// sent to the wildcard BSSID). A group frame the access point relays back to its source is not heard there (spec M11 §6).
    func hears(_ f: EthernetFrame) -> Bool {
        guard let h = f.air, f.src != iface.mac else { return false }
        if f.receiver == iface.mac { return true }
        let bss: Mac? = self is ApRadio ? BROADCAST_MAC : bssid
        return isGroupMac(f.receiver) && h.bssid == bss
    }

    /// On the air with `header` and the next sequence number.
    func transmit(_ frame: EthernetFrame, _ header: Dot11Header) {
        var f = frame
        f.air = header
        f.air!.seq = seq
        seq = (seq + 1) % 4096
        sim.medium(channel).transmit(f, from: self)
    }

    func sendMgmt(_ m: Dot11Mgmt, to dst: Mac, bssid: Mac) {
        transmit(EthernetFrame(id: sim.nextId(), src: iface.mac, dst: dst, etherType: 0, payload: .mgmt(m)), Dot11Header(bssid: bssid))
    }
}

/// A Wi-Fi client's radio (spec M11 §5): active scanning, Open System authentication, association with the first access point that
/// answered. It stores no timers: a callback acts only if `generation` is unchanged since it was scheduled (as in `DhcpClient`).
final class StationRadio: Radio {
    private(set) var config = StationConfig()
    private(set) var state = StationState.idle
    /// The access point it chose, from authentication on.
    private(set) weak var ap: ApRadio?
    /// The first access point that answered the scan under way, and the channel it announced.
    private weak var found: ApRadio?
    private var foundChannel = 0
    private var generation = 0

    init(iface: Interface) {
        super.init(iface: iface, channel: WIFI_CHANNELS[0])
    }

    override var bssid: Mac? { ap?.iface.mac }
    override var lineUp: Bool { state == .associated }

    /// A new network (spec M11 §5): leaving an access point says so with a Deauthentication (reason 3), then the scan starts over.
    func configure(_ c: StationConfig) throws {
        try checkSsid(c.ssid, empty: true)
        guard c != config else { return }
        if state == .associated, let ap { sendMgmt(.deauthentication(reason: DOT11_REASON_LEAVING), to: ap.iface.mac, bssid: ap.iface.mac) }
        config = c
        restart()
    }

    /// Scans again from channel 1 after leaving any access point; idle without a network or while switched off. Also how an access
    /// point's going away (switched off, removed, a Deauthentication) reaches the station.
    func restart() {
        leave()
        guard iface.node.powered, !config.ssid.isEmpty else { return }
        state = .scanning
        later(0) { $0.scan(0) }
    }

    /// Switched off or removed (spec M11 §5): the access point forgets it at once, without a frame.
    func reset() {
        ap?.forget(self)
        leave()
    }

    /// Back to idle with every timer void; a line that was up goes down (IPv6 and DHCP follow, spec M11 §5).
    private func leave() {
        let wasUp = state == .associated
        generation += 1
        state = .idle
        ap = nil
        if wasUp { iface.node.linkChanged(iface) }
    }

    private func later(_ delay: Int, _ action: @escaping (StationRadio) -> Void) {
        let gen = generation
        sim.sched.after(delay) { [self] in
            if gen == generation { action(self) }
        }
    }

    /// Active scanning (§11.1.4.3): a Probe Request for the SSID on each channel in turn, listening SCAN_DWELL_NS on each.
    private func scan(_ k: Int) {
        if k == 0 {
            state = .scanning
            found = nil
        }
        guard k < WIFI_CHANNELS.count else { return choose() }
        channel = WIFI_CHANNELS[k]
        sendMgmt(.probeRequest(ssid: config.ssid), to: BROADCAST_MAC, bssid: BROADCAST_MAC)
        later(SCAN_DWELL_NS) { $0.scan(k + 1) }
    }

    /// The scan is over: authenticate with the first access point that answered, or scan again in RESCAN_NS.
    private func choose() {
        guard let found else {
            state = .notFound
            return later(RESCAN_NS) { $0.scan(0) }
        }
        ap = found
        channel = foundChannel
        state = .authenticating
        sendMgmt(.authentication(seq: 1, status: 0), to: found.iface.mac, bssid: found.iface.mac)
        later(DOT11_TIMEOUT_NS) { $0.restart() }
    }

    override func receive(_ f: EthernetFrame, from sender: Radio) {
        guard case .mgmt(let m) = f.payload else {
            // Data from its access point, once associated.
            if state == .associated { iface.node.receive(f, on: iface) }
            return
        }
        let fromAp = f.src == bssid
        switch m {
        case .probeResponse(let ssid, let channel, _) where state == .scanning && ssid == config.ssid && found == nil:
            found = sender as? ApRadio
            foundChannel = channel
        case .authentication(seq: 2, status: 0) where state == .authenticating && fromAp:
            generation += 1
            state = .associating
            sendMgmt(.associationRequest(ssid: config.ssid), to: f.src, bssid: f.src)
            later(DOT11_TIMEOUT_NS) { $0.restart() }
        case .associationResponse(status: 0, aid: _) where state == .associating && fromAp:
            generation += 1
            state = .associated
            iface.node.linkChanged(iface)
        case .deauthentication where fromAp:
            restart()
        default:
            break
        }
    }
}

/// An access point's radio (spec M11 §2, §5): one SSID on one channel; it answers probes for its SSID, authenticates (Open System)
/// and associates every station that asks, numbering them from AID 1.
// ponytail: no per-station authentication state; the stations here always authenticate before they associate
final class ApRadio: Radio {
    /// One association: what the radio side of the bridge knows of a station (spec M11 §6).
    struct Client {
        let aid: Int
        let station: StationRadio
    }

    private(set) var config = ApConfig()
    /// By AID.
    private(set) var clients: [Client] = []

    init(iface: Interface) {
        super.init(iface: iface, channel: ApConfig().channel)
    }

    override var bssid: Mac? { iface.mac }
    override var lineUp: Bool { !clients.isEmpty }

    /// A new SSID or channel (spec M11 §5): a group Deauthentication (reason 3) on the old channel; the stations scan again when they
    /// hear it.
    func configure(_ c: ApConfig) throws {
        try checkSsid(c.ssid, empty: false)
        guard WIFI_CHANNELS.contains(c.channel) else { throw EngineError("Channel must be 1, 6 or 11") }
        guard c != config else { return }
        if !clients.isEmpty { sendMgmt(.deauthentication(reason: DOT11_REASON_LEAVING), to: BROADCAST_MAC, bssid: iface.mac) }
        clients = []
        config = c
        channel = c.channel
    }

    func forget(_ s: StationRadio) {
        clients.removeAll { $0.station === s }
    }

    /// Switched off or removed (spec M11 §5): every station knows at once, without a frame, and scans again.
    func dropAll() {
        let gone = clients
        clients = []
        for c in gone { c.station.restart() }
    }

    override func receive(_ f: EthernetFrame, from sender: Radio) {
        guard case .mgmt(let m) = f.payload else { return iface.node.receive(f, on: iface) }
        guard let station = sender as? StationRadio else { return }
        switch m {
        case .probeRequest(let ssid) where ssid == config.ssid:
            sendMgmt(.probeResponse(ssid: ssid, channel: config.channel, timestamp: sim.now / US), to: f.src, bssid: iface.mac)
        case .authentication(seq: 1, status: _):
            sendMgmt(.authentication(seq: 2, status: 0), to: f.src, bssid: iface.mac)
        case .associationRequest(let ssid) where ssid == config.ssid:
            let aid = clients.first { $0.station === station }?.aid ?? freeAid()
            if !clients.contains(where: { $0.station === station }) {
                clients.append(Client(aid: aid, station: station))
                clients.sort { $0.aid < $1.aid }
            }
            sendMgmt(.associationResponse(status: 0, aid: aid), to: f.src, bssid: iface.mac)
        case .deauthentication:
            forget(station)
        default:
            break
        }
    }

    private func freeAid() -> Int {
        var aid = 1
        while clients.contains(where: { $0.aid == aid }) { aid += 1 }
        return aid
    }
}
